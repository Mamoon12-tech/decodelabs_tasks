## About

A single-file portfolio built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies, no build tools. Just one `index.html` that loads fast anywhere in the world.

Designed with a dark editorial aesthetic — custom cursor, scroll animations, ticker bar, and a full magazine-style layout covering everything: experience, projects, skills, education, and certifications.

## Hosting

This portfolio is hosted on **GitHub Pages** — free, globally distributed, no server required.

It was built as the **DecodeLabs Cloud Computing Project 1** deliverable — demonstrating serverless static site hosting. Same concept as AWS S3 / Azure Blob Storage, deployed via GitHub's CDN infrastructure.
