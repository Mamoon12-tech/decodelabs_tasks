// Concepts Learned
🗄️
What is a Database?
Organized storage for data. Like Excel but smarter — structured, searchable, and scalable to millions of records.
☁️
AWS RDS
Amazon's managed database service. AWS handles the hardware and OS. You just manage the data and schema.
🔑
Primary Key
Every row has a unique ID. Like a national ID number — no two records can have the same one.
🚫
NOT NULL
This field cannot be left empty. Forces complete data entry — no blank names or missing emails allowed.
🔒
Private Subnet
Database placed inside a private network — no direct internet access. A public database is a compromised database.
🐍
Python + SQLite
Used to simulate the database locally. Same SQL commands work on AWS RDS — only the connection changes.
